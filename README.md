# midi2pico8

A small utility that maps MIDI input to keyboard keys for use in PICO-8. Based on [https://github.com/thestk/rtmidi](RtMidi).

## Instructions

 * run midi2pico8.exe
 * plug in MIDI device
 * use the MIDI device to input keys in the PICO-8 tracker
